Symbol and 'more symbols' pages plus a dedicated number pad shown automatically for numeric fields and reachable manually.

## Acceptance criteria

- [x] Symbols, more symbols, a number pad and a phone pad
- [x] Number fields open the number pad
- [x] The number pad can also be opened by hand from the symbols pages

## Tasks

- [x] Check on the Pixel

## Progress

Symbols, more symbols, number pad, phone pad; the number pad opens automatically for number fields and by hand by holding ABC on the symbols pages (as on Gboard), ABC returns to letters. Verified on the Pixel 6 Pro (the 1234 label fits on one line).
